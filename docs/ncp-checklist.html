담당 제안 A: VPC·서브넷, Cloud DB, Object Storage / E: 서버, ACG, NAT, 로드밸런서, 인증서·도메인, Nginx. 만든 사람이 리소스 대장에 바로 기록해요.

3-1. VPC · 서브넷

서브넷예시 대역종류쓰임

4-2. Web 서버 (Nginx)

server {
  listen 80;
  client_max_body_size 20m;              # 답변 녹음(수 MB) 업로드. 기본 1MB면 실패

  root /var/www/yeohaengmal;             # 프론트 dist
  location / { try_files $uri /index.html; }   # React Router 새로고침 대응

  location /api/ {
    proxy_pass http://<WAS 사설 IP>:8080/;   # 끝의 / 가 /api 접두를 제거
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $http_x_forwarded_proto;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 90s;
    proxy_send_timeout 90s;
  }
}

리소스 대장 속성

리소스, 이름, 종류·사양, Zone/서브넷, 담당, 생성일, 상태(켜짐/정지/삭제), 비밀 위치, 비고. 값 자체(키·비밀번호)는 쓰지 않고 "어디에 보관했는지"만 적어요.

노트 맨 위에 고정할 비밀 정보 규칙

  • 키·비밀번호는 노트·채팅·깃·스크린샷에 평문으로 올리지 않는다.
  • 팀 비밀번호 관리 도구에 항목으로 보관하고, 노트에는 항목 이름만 적는다.
  • 각자 .env(깃 제외)에 두고, 환경 변수 이름은 백엔드 .env.example과 똑같이 쓴다.
  • 키가 노출되면 즉시 재발급하고 팀에 공지한다.
